## 运行

```bat
双击 run.bat          （推荐）
# 或手动：
cd tetris3d
D:\tetris3d-venv\Scripts\python.exe main.py
```

首次运行 `run.bat` 会在 `D:\tetris3d-venv` 自动创建虚拟环境并安装依赖（pygame / numpy）。
也可以自行建环境：

```
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python main.py
```

> 说明：项目运行环境与代码统一放在 D 盘（`D:\tetris3d` + `D:\tetris3d-venv`），避开 C 盘空间紧张的问题。

产物：`dist\Tetris3DRush.exe`（约 29MB）。打包要点：

- PyInstaller 已安装在本机 D 盘 venv（`D:\tetris3d-venv`），安装与构建全程 `--no-cache-dir`，

## 七种模式（竞速为主）

| 模式 | 目标 | 特点 |
|---|---|---|
| 竞速 20 行 | 最快消 20 行 | 热手冲刺，自动下落速度可调 |
| 竞速 40 行 | 最快消 40 行 | 毫秒计时 + PPS 统计，速通主模式 |
| 竞速 100 行 | 最快消 100 行 | 长线速通 |
| 马拉松 1500 | 达成 1500 分 | 经典升级节奏（等级 × 重力公式） |
| 限时 120 秒 | 120 秒内冲击最高分 | 顶部剩余倒计时，记录最高分 |
| 奶酪突击 40 | 最快清 40 行 | 场地预埋 10 行乱序垃圾，填洞破局 |
| 无尽生存 | 撑得越久越好 | 每 20 秒重力加速一档，记录最长生存 |

每种模式独立保存**最佳纪录**（`records.json`），破纪录时结算页亮出 ★ 新纪录。

## 玩法特性

- **7-bag 随机**：每 7 块一组不重复，消除"连吃两个 S/Z"的运气差
- **SRS 踢墙**：完整踢墙表，T 旋/I 旋贴墙、顶墙都能转
- **暂存（Hold）** 与 **5 格 NEXT 预览**，幽灵投影
- **T-spin 判定**：三角落法 + 旋转标记，区分 full / mini；T-spin Triple 计分
- **指南计分**：连击（×50 递增）、Back-to-Back ×1.5、Perfect Clear +3500、硬降 ×2/格
- **锁定延迟 500ms**（最多重置 15 次，防无限蹭）
- **DAS / ARR / 自动下落 / 视角灵敏度可调**；自动下落支持关闭、极慢、慢速、标准和快速
- **键位完全自定义**：设置 →「自定义键位」，支持冲突键位自动交换与一键恢复默认
- **可缩放窗口 / 全屏**：可直接最大化窗口；`F11` 或 `Alt+Enter` 切换全屏，全屏时按 `Esc` 返回窗口

## 操作

| 键 | 功能 |
|---|---|
| ← → | 移动 |
| ↓ | 软降 |
| ↑ | 顺时针旋转 |
| Z | 逆时针旋转 |
| A | 180° 旋转 |
| C | 暂存 Hold |
| 空格 | 硬降 |
| Q / E | 旋转 3D 视角（左 / 右） |
| 按住鼠标拖拽 | 360° 自由转动视角 + 俯仰 |
| V | 复位视角 |
| F | 切换到传统正面视角 |
| Esc | 暂停 |
| R | 重开 |
| Enter | 确认（菜单） |
| F11 / Alt+Enter | 切换全屏；全屏时 Esc 返回窗口 |

以上为默认键位。移动、软降、旋转、硬降、暂存、暂停、重开和 3D 视角操作均可在
「设置 → 自定义键位」中重新绑定；设置会自动保存。

> 视角默认是右上等距，随时可用 Q/E 或低灵敏度鼠标拖拽转到任意角度，也可按 F
> 直接进入传统正面视角。方位角可完整旋转 360°，俯仰可从近地平线移动到接近垂直俯视。

## 个性化定制

- **方块材质（6 套）**：霓虹 / 水晶 / 金属 / 像素 / 糖果 / 流光 —— 改变三面明暗、饱和度、描边粗细、顶面装饰与辉光，HOLD/NEXT 预览同步跟随。设置 →「方块材质」← → 切换
- **现代标准配色**：I 青、O 黄、T 紫、S 绿、Z 红、J 蓝、L 橙
- **背景主题（5 套 + 自定义）**：深蓝霓虹 / 星云深空 / 城市夜景 / 极光流 / 赛博网格 —— 全部程序化生成并带流动动画。设置 →「背景主题」← → 切换
- **上传背景图**：设置 →「上传背景图…」回车或点击，弹出文件选择框（png / jpg / bmp / gif），图片自动裁剪铺满窗口并叠加暗层，保证方块清晰；主题自动切到「自定义图片」。选择路径保存在 `settings.json`，重启游戏自动生效
- 设置自动持久化到 `settings.json`（DAS / ARR / 自动下落 / 视角灵敏度 / 音效 / 材质 / 背景 / 全屏 / 键位）；打包版保存在 EXE 同目录，不会再写入临时解包目录

## 伪 3D 渲染细节

- **360° 自由视角**：方位角无死角旋转，地面深度与方块高度分别按相机仰角投影；Q/E 或拖拽转动，F 正面、V 复位
- 等距投影：`x = (c−r)·CELL·cosθ − (c+r)·CELL·sinθ`，画家算法按旋转后的深度排序
- 每格方块 = 顶面（亮）/ 东面（中）/ 南面（暗）三面立方体，侧面绘制顺序随视角翻转
- 单层悬浮平台网格（不会再与第二层网格重叠）+ 活动方块接触阴影
- 方块使用视角相关的定向明暗、顶面微倒角、高光边和接触遮蔽；活动块不再以大面积辉光污染邻近方块
- 全屏缩放使用锐利像素映射，字体粗体直接加载微软雅黑粗体字形，避免二次平滑造成的模糊边缘
- 消行：白色闪光带 → 方块爆裂粒子 + 冲击波圆环 + 震屏（Tetris 震得最狠）
- 堆叠接近顶部时红色告警暗角 + 警告音

## 代码结构

```
tetris3d/
├── main.py                  # 入口（含 --shot 无头截图模式）
├── run.bat                  # 一键启动
├── requirements.txt
├── tetris_game/
│   ├── constants.py         # 布局/颜色/手感参数
│   ├── pieces.py            # 方块定义、旋转生成、SRS 踢墙表、7-bag
│   ├── board.py             # 场地逻辑：碰撞/锁定/T-spin/计分/消行
│   ├── renderer.py          # 伪 3D 等距渲染、粒子、光效
│   ├── ui.py                # 字体/面板/按钮/HUD/迷你预览
│   ├── audio.py             # numpy 程序化合成音效（无素材依赖）
│   └── game.py              # 状态机、输入（DAS/ARR）、菜单与结算
└── tests/
    ├── test_logic.py        # 88 项核心逻辑单测
    └── test_smoke.py        # 无头游玩/通关链路冒烟测试
```
